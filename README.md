# Drahem-web

Version web installable de l'application **Drahem** (gestion d'argent).

👉 **https://belaidiamar1-arch.github.io/Drahem-web/**

Sur iPhone : ouvrir le lien dans Safari → Partager → « Sur l'écran d'accueil ».

Ce dépôt ne contient que l'application compilée, publiée automatiquement depuis le dépôt
privé du code source. Aucune donnée personnelle n'y est stockée : vos comptes et opérations
restent uniquement sur votre téléphone.
